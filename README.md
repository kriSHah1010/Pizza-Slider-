# Pizza Slider Vite Project

This repo is a Vite app. Follow these steps to run it on Windows.

## What you need

- Node.js installed
- npm installed (comes with Node.js)

Check your version:

```powershell
node -v
npm -v
```

Vite in this project needs a modern Node version. Node 20.19+ or 22.12+ is recommended. Node 24 also works.

## Run the project

Open PowerShell in the project folder:

Install dependencies:

```powershell
npm install
```

Start the dev server:

```powershell
npm run dev
```

Open the local URL shown in the terminal, usually:

```text
http://localhost:5173/
```
